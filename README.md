# EcoTrack
Eslogan: Conoce tu impacto. Actúa por tu planeta.
EcoTrack es una aplicación web para el monitoreo ambiental, participación ciudadana y reducción del impacto ambiental.
## Estructura del Proyecto
ecotrack/
├── frontend/     # Aplicación cliente en Angular
├── backend/      # API REST en Node.js, Express y TypeScript
├── database/     # Migraciones y semillas SQL para PostgreSQL/PostGIS
├── README.md
└── package.json
